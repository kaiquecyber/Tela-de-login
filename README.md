# 🏦 NJR BANK — Sua próxima jogada

**Uma interface de login conceitual para um banco digital, com design sofisticado inspirado no universo do Neymar Jr.**

O NJR BANK é um projeto de desenvolvimento front-end que apresenta uma tela de acesso com identidade visual moderna, combinando tons de preto e dourado para transmitir elegância, exclusividade e inovação.

## ✨ Funcionalidades e elementos visuais

- **Tela de login:** interface para acesso à conta.
- **Campo de CPF:** entrada do identificador do usuário.
- **Campo de senha:** entrada protegida visualmente por caracteres ocultos.
- **Botão de acesso:** botão estilizado para entrar na conta.
- **Recuperação de senha:** link disponível na interface.
- **Abertura de conta:** link para novos usuários.
- **Efeitos visuais:** animação de flutuação do cartão e efeitos de foco nos campos.
- **Identidade visual:** paleta de cores em preto, dourado e tons neutros.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação dos elementos da página.
- **CSS3:** estilização, layout, efeitos visuais e animações.

## 🎨 Identidade visual


O projeto utiliza uma combinação de cores que reforça a proposta de um banco digital premium.
